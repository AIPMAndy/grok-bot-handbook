# Skill 模板：把一次真实成功保存成 SOP

> Skill = 怎么做；Routine = 何时由谁去做。两者不要混淆。

- Skill 名称：{名称}
- 使用时机：{满足什么输入条件才执行}
- 输入资料：{格式、时效、权限}
- 可用工具：{允许的最小范围}
- 步骤：①{读取} ②{处理} ③{核验} ④{交付}
- 输出格式：{清单 / Markdown / 表格 / 文件}
- 质量门槛：{来源、数量、时效与抽样检查}
- 失败处理：{无权限/缺数据/页面变更/额度不足时如何停止}
- 需要人工批准：{发送、发布、付款、删除、生产变更}
- 验证：{第二份安全数据回测结果}

可对 Bot 说：

> 把我们刚才通过审核的流程保存为名叫「{名称}」的 Skill。明确输入、权限、逐步操作、证据、检查点、失败处理、不可自动进行的动作。先返回草稿让我确认，并用另一份安全数据测试，未通过之前不要建立 Routine。

官方参考：[Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations)。
