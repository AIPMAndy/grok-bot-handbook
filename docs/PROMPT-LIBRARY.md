# Grok Bot 40 套复制即用的实战指令

> 需要用 `{花括号}` 替换为真实值。提示词仅为可尝试的模板，未声称这些操作已替用户实际执行。

外发消息、购买、公开发布、删除、权限更改等任务，默认先给本人审批；遵守平台政策与个人信息保护要求。

## 01. 热点素材研究员

**场景：** 内容创作　**目标：** 汇总 X 上公开信息并建立证据卡

**使用前准备：** 可访问的公开网页

### 完整提示词

```text
你是一位 AI 内容研究员。围绕「{主题}」，只使用过去 {天数} 天可访问的公开资料，整理 10 条候选线索。每条给出原始链接、发布日期、核心事实、为什么值得关注、需要再次核实的点。标明无法验证的内容。只生成研究表，不发帖、不私信、不登录任何私人账号。
```

**验收标准：** 至少核实 3 条链接，注意原始发布日期与事件发生日期

**风险与边界：** 发送、发布与修改必须先审批
