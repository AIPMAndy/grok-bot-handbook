# 中文用户常见使用边界

1. **网络可访问性**：官方能下载和使用不代表任何地域或单位网络都可用。出现网络问题先查官方服务状态、所在网络及合规的访问方式；本教程不提供规避封锁或绕过安全验证的方法。
2. **微信、X、Threads、招聘平台**：Bot 技术上可能能操作界面，不代表平台同意自动抓取、群发或模拟人类账户行为。批量陌生人骚扰与未授权个人信息采集不属于本站推荐的流程。
3. **候选人资料与客户对话**：确保有授权、最小必要且已脱敏。不要将身份证、私人手机号、合同敏感条款和付款资料直接贴进公开 Bot 模板。
4. **商业推广**：自有作品可以配官网和服务入口，不能以保证加薪、保证接单或伪造客户业绩诱导付费。
5. **支付与法务**：本项目不是法律、税务或平台合规意见；实际处理信息和账户前检查所适用地区的政策与组织要求。

推荐先把工作范围控制在**公开资料研究、内部草稿、人工确认**三类。在有书面授权和充分安全测试前，不建议自动外发或生产写入。
