## 修复仍有边界

- 官方网址能访问不保证不同账户同样显示按钮；产品实测仍需正式授权账户。
- 浏览器界面测试检查的是**本项目**网站，不代表测试了 Grok Bot 产品。
- 不能证明“全网第一”；本项目的目标是实现可公开验证的覆盖率、文档正确率和高风险修复速度。
- 高风险业务不建议在未经审阅情况下配置自动外发或付款。

## 发布门禁

- 自动流程：事实台账不过期 → 数据由源码重建且无差异 → 静态测试 + JS 语法检查 → 网站部署。
- 手动流程：实际浏览器移动/桌面复测、已授权 Grok Bot 产品案例、外部 URL 访问核实、开源许可证核查。
- 在线仓库尚不存在时，仅能交付可部署 ZIP，不宣称已上线。
