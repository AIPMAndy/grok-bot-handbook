- 不把官方 Grok Bot 与同名第三方开源项目混为一谈。
- 不静态承诺订阅价格、额度、地区可用性或运行效果。
- 任何自动外发、付款、删除、权限与生产更改均建议人工审批。
- 官方页面描述产品能力不等同于本作者已经实测所有功能。
