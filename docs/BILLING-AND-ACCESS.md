# Grok Bot 订阅、登录与每周用量｜防买错版

> **重要：套餐可能调整。** 本页对照 2026-10-21 可访问的 [Cursor 官方计划矩阵](https://cursor.com/help/grok-bot/plans)、[x.ai 产品入口](https://x.ai/bot)。**不要把本页当结账报价单**。

## 第一步：先判断属于哪种体系

| 你看到的账户/套餐 | Grok Bot 访问情况 | 具体怎么做 | 用量与费用判断 |
|---|---|---|---|
| 新版 **The X Subscription Premium / Super / Ultra** | 官方显示包含 | 使用对应账户登录 Grok Bot；不走旧版关联流程 | 与订阅相关产品共享每周用量池；额外使用看当前预付/充值政策 |
| 新版 **The X Subscription Plus / Free** | 官方显示不包含 | 在官方账单页检查升级选项 | 不要为了 Bot 盲目续费无权限计划 |
| 旧版 **Cursor Pro / Pro+ / Ultra**（付费） | 官方显示符合条件 | 用匹配 Cursor 账户登录 | 旧版额度和按需设置独立查看 |
| 旧版 **Cursor Teams** | 官方显示符合条件，但旧政策可能例外 | 企业成员使用对应工作账户；必要时问管理员 | 额度依组织计划，先看后台 |
| 旧版 Cursor 通过 **SuperGrok / SuperGrok Plus / Heavy** 获资格 | 仅在符合关联规则时 | 由 Grok Bot 官方入口完成账户关联 | 和新套餐用量机制可能不同 |
| 旧版 Cursor 通过 **X Premium+** 关联 | 官方目前列有此授权路径 | 先确认自己真的是 Premium+，不是普通 X Premium | 不可擅自推定所有 X 计划都有权益 |
| 旧版企业与 Grok Business | 需按席位与企业配置核实 | 由组织管理员/官方页面核对 | 依组织后台计算 |

**极易混淆：** 新版的 **The X Subscription Premium** 与社交平台旧名称 **X Premium / X Premium+** 不等价。“Premium”三个字一样不代表权益一样。

## 第二步：进入账户核实这 5 项

- [ ] 官方后台实际显示的订阅体系与套餐名
- [ ] Grok Bot 是否 Included / Active
- [ ] Weekly usage 当前区间与重置窗口
- [ ] 可选额外付费方式及是否启用了自动加额
- [ ] 团队席位和账户关联是否与当前登录邮箱一致

## 第三步：控制运行成本

设一个自己的硬阈值：**没有理解支付路径之前不启动连续自动化**。对于新版共享周池，记录当前周实际使用以及下周重置，不把 Bot 次数直接等同于费用。

建议每周审视四个指标：任务成功数、人工复核工时、错误/重跑次数、额外费用。节省时间要扣掉复核与维护成本。

## 常见误买场景

**场景 A**：已经有 X Premium（不带 +），想问 Grok Bot 能不能用。答：不能据此推断；看当前官方计划矩阵与自己的账户。

**场景 B**：看到旧文章声称 Bot 用量与 Grok 完全分开。答：这可能描述旧版权限；新版 The X Subscription 目前共用每周用量池。

**场景 C**：公司账号打不开，但私人付费账户能进。答：先看组织权限/SSO/Legacy Privacy Mode；不要私自绕过组织策略。
