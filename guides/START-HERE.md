# 十分钟起步：从 0 到你的第一个 Grok Bot

> 这套教程面向官方 [x.ai/bot](https://x.ai/bot)，不是第三方 GrokBot 脚本。实际安装和电脑初始化时长随系统、网络和账号而变化。

## 先确认能用

打开 [官方资格说明](https://docs.x.ai/grok-bot/get-started)：先打开 [最新版官方套餐矩阵](https://cursor.com/help/grok-bot/plans)：新版 The X Subscription Premium/Super/Ultra 包含 Grok Bot，Plus/Free 不包含；旧版 Cursor 与部分 SuperGrok/X Premium+ 关联方式需分别核对。新套餐可共享每周用量池，不能用旧文档猜预算。更多细节见 [订阅防坑指南](../docs/BILLING-AND-ACCESS.md)。

## 安装与登录

从官方页面下载对应 Mac（Apple silicon / Intel）、Windows（x64 / Arm64）或 Linux 客户端。按当前套餐与官方登录流程使用正确账户；部分旧版 Cursor 账户需要关联符合条件的 SuperGrok/X Premium+，新版 The X Subscription 可能不需要此步骤。出现云电脑配置提示时按官方引导完成。

## 创建你的第一位 AI 同事

名字：`Research Bot`  
职责：针对一个明确主题搜集公开资料，形成可追溯清单。  
要求：每条必须附来源，不能生成未经证实的事实。  
边界：不能自动发送邮件、发布内容、付款、删除文件或修改权限。

**复制第一次任务：**

> 请围绕「{我关注的行业}」收集近 7 天公开发布的 8 条重要信息。输出表格：标题、公开来源链接、原始发布日期、核心事实、可能影响、待核实点。缺少信息必须写“未知”，禁止编造。先给研究结果，不发帖、不联系任何人、不修改我的应用或账号。请说明最终完成和未完成的步骤。

## 验收

能拿到结构化成果；随机打开至少 3 个链接；日期与原文一致；Bot 没有自动执行外部发信/发布。完成后让它把可靠流程保存为 Skill，复测后再考虑 Routine。

## 如果卡住

先检查是否缺授权、仍在登录、等待审批、订阅额度已满；参考 [故障排查](../docs/TROUBLESHOOTING.md)。
